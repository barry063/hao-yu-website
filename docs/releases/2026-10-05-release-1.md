source section, evidence category and review date. It also records SHA-256 values

## Browser limitation and remaining release gate

The Browser plugin could not initialise: `privileged native pipe bridge is not
available; browser-client is not trusted`. A recovery call initially failed because
the approval-review model was at capacity; a later diagnostic succeeded and
confirmed there was no initialised browser agent. This is not a successful browser
connection or a safety rejection of the website changes.

Local preview checks initially hit the sandbox's networking restriction. Approved
execution of the server/client in one process passed. The user-facing preview is
running outside the sandbox at `http://localhost:8081/hao-yu-website/` for this
session. A preview process is temporary; future sessions can run `npm run preview`.
