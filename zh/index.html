01 / 个人简介

材料生长与光学表征

我是剑桥大学Hofmann 课题组的工程学博士研究生，主要研究钨氧化物和过渡金属二硫属化合物。博士研究关注源材料的化学性质、源材料与衬底的布置方式，以及工艺条件对材料生长的影响。

我独立开展 SEM／EDS 和拉曼／PL 测量，也使用 Bruker XRD 采集和分析钨氧化物及亚氧化物的数据，结合参考图谱匹配，开展物相鉴定与晶格参数分析。

我将实验表征与局部输运模拟相结合，并分析合作者采集的 operando SEM 图像。我开发的 RamanPL_2D 可用于光谱拟合、空间映射和结果整理。在牛津期间，我还参与了光子器件的测量、设计与模拟。

02 / 研究方法

材料制备、实验表征与数据分析

材料生长与前驱体输运

通过近空间 CVD 实验和局部输运模拟，研究前驱体化学及源材料与衬底的布置方式如何影响低维氧化物和硫化物的形成。

显微、光谱与结构表征

独立开展 SEM／EDS、拉曼／PL 和 Bruker XRD 测量，分析不同工艺条件下材料的形貌、元素组成、晶体结构与光学响应。

科研软件与数据分析

针对材料实验中的光谱分析需求，开发 Python 工具，用于数据预处理、峰拟合、空间映射与批量导出。

材料生长、光谱分析与光子器件

以下介绍我的博士研究、光谱分析软件及在牛津开展的光子器件研究。

2023年2月 – 2025年1月

钨氧化物与硫化物纳米结构的近空间生长

研究受限空间中的气相输运及生长结构对氧化物、硫化物纳米结构形成的影响。

我设计并开展 CSS 辅助 CVD 生长实验和拉曼／PL 测量，与 Stephan Hofmann 共同撰写了第一作者论文。博士论文还包括我的非原位 SEM 测量，以及对合作者采集的 operando SEM 图像的分析。

Operando SEM、TEM／EDX 和 XPS 数据由合作者采集。结合生长实验与表征结果，我们研究前驱体供给和生长条件与材料形成之间的关系。

第一作者论文 · Nanoscale ↗

2025年6月 – 2026年4月

NaCl 辅助的 WS₂ 近空间生长

研究源材料处理方法及源材料与衬底的布置方式对平面 WS₂ 生长的影响。

我设计了近空间生长结构，结合 COMSOL 局部流动模拟与 CVD 对比实验，评估前驱体供给及源材料与衬底之间的交叉污染。

通过对源材料和衬底进行配对表征，并结合拉曼／PL 测量，分析生长条件与材料形成的关系。我还独立采集了 NaCl 处理后的 SiO₂／Si 对照样品的 SEM-EDS 光谱和元素分布图，确认生长前的盐沉积。

这项研究是我已提交的博士论文的一部分；相关第一作者稿件仍在准备中。

2025年6月 – 8月

直接写入 MoS₂ 的光学表征

利用光谱表征分析直接写入二维材料的层结构和光学响应。

在闭环 MoS₂ 写入的合作研究中，我开展拉曼／PL 测量和空间映射，分析不同位置的层结构及光学响应差异。生长平台和其他配套测量由其他共同作者主导。

合作论文状态：审稿中。
